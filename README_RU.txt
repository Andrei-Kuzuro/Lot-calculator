Lot Calculator PWA — версия без двойного зума.

Изменения:
- отключён двойной тап для увеличения страницы;
- запрещён pinch/gesture zoom;
- добавлен touch-action: manipulation;
- клавиатура увеличена на 15% (до 28.75vh, максимум 250px);
- расстояние между кнопками увеличено с 4px до 6px;
- системная клавиатура iPhone не вызывается.

Для обновления уже установленной PWA:
1. Замените файлы на GitHub Pages содержимым этого архива.
2. Если старая версия не обновилась сразу, откройте сайт в Safari, обновите страницу и снова запустите PWA.
