LOT CALCULATOR — PWA

Что внутри:
- index.html — веб-версия
- manifest.webmanifest — описание PWA
- sw.js — офлайн-кэш
- icons/ — иконки приложения

Порядок инструментов:
1. Криптоактивы: BTCUSD, ETHUSD
2. Драгоценные металлы: XAUUSD
3. Индексы: USSPX500, JAPAN225, GERMANY40, US100, GER40
4. Валютные пары

Клавиатура:
- системная клавиатура iPhone не вызывается;
- поля только для чтения;
- используется только встроенная цифровая клавиатура;
- '.' — десятичный разделитель;
- «Готово» — скрывает клавиатуру.

Публикация через GitHub Pages:
1. Создайте публичный GitHub repository, например lot-calculator.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень repository.
3. GitHub -> Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.
7. Откройте выданный https://USERNAME.github.io/lot-calculator/ в Safari на iPhone.
8. Safari -> Поделиться -> На экран «Домой» -> Добавить.

Ссылку можно давать другим людям. Если repository и GitHub Pages публичные, любой человек с URL сможет открыть калькулятор в браузере и добавить его на свой экран «Домой». Никаких аккаунтов GitHub пользователям не требуется.
