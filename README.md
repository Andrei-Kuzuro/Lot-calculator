# 📊 Lot Calculator (Калькулятор лота)

Легкий и быстрый Progressive Web App (PWA) калькулятор для расчета размера торговой позиции. Оптимизирован для мобильных устройств (особенно iOS), работает офлайн и устанавливается на главный экран как нативное приложение.

## ✨ Возможности
- 📱 **Нативная клавиатура**: Поля ввода автоматически открывают цифровую клавиатуру (`inputmode="decimal"`).
- 🔄 **Умный ввод**: Автоматическая замена запятых на точки при вводе и вставке из буфера обмена.
- 💾 **Сохранение настроек**: Депозит и процент риска сохраняются в памяти устройства.
- 📉 **Определение направления**: Автоматически показывает, является ли сделка LONG или SHORT.
- 🌐 **Офлайн-режим**: Работает без интернета благодаря Service Worker.
- 🎯 **Поддержка инструментов**: Криптовалюты, Форекс, Индексы и Золото.

## 🚀 Как использовать
1. Открой ссылку на GitHub Pages (если включена) или скачай репозиторий.
2. На iPhone: нажми "Поделиться" → "На экран «Домой»".
3. На Android: нажми меню браузера → "Установить приложение".
4. Введи размер депозита, риск, цену входа и стопа.
5. Нажми "Рассчитать лот".

## 🛠 Технологии
- HTML5, CSS3 (CSS Variables, Grid)
- Vanilla JavaScript (ES6+)
- Progressive Web App (Manifest, Service Worker)

## 📝 Примечание
Значения стоимости пункта (`pipValue`) для индексов и некоторых кросс-курсов усреднены. Для максимальной точности сверяйся со спецификацией контрактов твоего брокера.
